{{< /blocks/hero >}} {{< blocks/section class="k8s-overview" >}} {{% blocks/feature image="flower" id="feature-primary" %}} [Kubernetes]({{< relref "/docs/concepts/overview/" >}}) is an open source system for running containers across a cluster of machines. Developed in the open by a [community](/community/) that spans the industry, Kubernetes has become the common foundation of the cloud native ecosystem. {{% /blocks/feature %}} {{< blocks/stats >}} {{% blocks/feature image="scalable" %}} #### Scalable Scale to match demand. Kubernetes adjusts the number of running instances automatically based on CPU, memory, or your own metrics, and grows from a single laptop to thousands of nodes without changing how you work. [Learn more →]({{< relref "/docs/concepts/workloads/autoscaling/" >}}) {{% /blocks/feature %}} {{% blocks/feature image="resilient" %}} #### Resilient Kubernetes keeps your applications running — restarting containers that fail, rescheduling them when a node goes down, and routing traffic only to instances that are ready. Recovery happens automatically, often before anyone notices. [Learn more →]({{< relref "/docs/concepts/workloads/controllers/deployment/" >}}) {{% /blocks/feature %}} {{% blocks/feature image="suitcase" %}} #### Portable Run the same way on a laptop, on-premises, or across public clouds. Kubernetes is open source with no vendor lock-in, so you can move workloads to wherever makes the most sense. [Learn more →]({{< relref "/docs/concepts/architecture/" >}}) {{% /blocks/feature %}} {{% blocks/feature image="blocks" %}} #### Extensible Kubernetes is a platform to build on. Define your own resource types, automate operations with custom controllers, and draw on a vast ecosystem of tools — all through the same API, without forking the core. [Learn more →]({{< relref "/docs/concepts/extend-kubernetes/" >}}) {{% /blocks/feature %}} {{< /blocks/section >}} {{< blocks/section id="video" background-image="video_banner_homepage_XNZvGHlpJ_4" >}}
