# Kubernetes Türkçe Dokümantasyonu (Turkish Documentation)

Kubernetes resmi dokümantasyonunun Türkçe yerelleştirme (localization) çalışma alanıdır.

## Katkıda Bulunma Rehberi

Kubernetes dokümantasyonuna katkı sağlamak için:
1. İlgili kavramın İngilizce sürümünü (`content/en/docs/...`) kaynak alınız.
2. Terminoloji tutarlılığına dikkat ediniz (Örnek: Pod, Service, Deployment, Namespace kavramları uluslararası Kubernetes standardı olarak korunur; açıklamaları ve rehberler Türkçe sunulur).
3. [Kubernetes Dokümantasyonuna Katkı Kılavuzu](https://kubernetes.io/docs/contribute/) kurallarına uyunuz.
