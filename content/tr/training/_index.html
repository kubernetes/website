Kubernetes Eğitimi ve Sertifikasyon Programları

Cloud Native Computing Foundation (CNCF) ve The Linux Foundation iş birliğiyle hazırlanan uluslararası geçerli sertifikalar ile bulut yerel uzmanlığınızı kanıtlayın:

  • CKA (Certified Kubernetes Administrator): Kubernetes Küme Yönetimi ve Operasyonları
  • CKAD (Certified Kubernetes Application Developer): Kubernetes Uygulama Geliştirme Uzmanlığı
  • CKS (Certified Kubernetes Security Specialist): Kubernetes Güvenlik ve Uyumluluk Uzmanlığı
  • KCNA (Kubernetes and Cloud Native Associate): Bulut Yerel Temelleri Giriş Sertifikası
