कस्टम रिसोर्स कुबरनेट्स API के एक्सटेंशन हैं। कुबरनेट्स आपके क्लस्टर में कस्टम रिसोर्स जोड़ने के दो
तरीके प्रदान करता है:

- [CustomResourceDefinition](/docs/concepts/extend-kubernetes/api-extension/custom-resources/)
  (CRD) तंत्र आपको एक API ग्रुप, kind, और स्कीमा के साथ एक नई कस्टम API को डिक्लेरेटिव रूप से
  परिभाषित करने की अनुमति देता है।
  कुबरनेट्स कंट्रोल प्लेन आपके कस्टम रिसोर्स को प्रदान करता है और उसके स्टोरेज को संभालता है। CRD
  आपको अपने क्लस्टर के लिए नए प्रकार के रिसोर्स बनाने की अनुमति देते हैं, बिना कोई कस्टम API सर्वर
  लिखे और चलाए।
- [एग्रीगेशन लेयर](/docs/concepts/extend-kubernetes/api-extension/apiserver-aggregation/) प्राइमरी
  API सर्वर के पीछे बैठती है, जो एक प्रॉक्सी के रूप में काम करता है।
  इस व्यवस्था को API एग्रीगेशन (AA) कहा जाता है, जो आपको अपना स्वयं का API सर्वर लिखकर और डिप्लॉय करके
  अपने कस्टम रिसोर्स के लिए विशेष कार्यान्वयन प्रदान करने की अनुमति देती है।
  मुख्य API सर्वर आपके द्वारा बताई गई कस्टम API के लिए अनुरोध को आपके API सर्वर पर अग्रेषित करता है,
  और उन्हें अपने सभी क्लाइंट के लिए उपलब्ध बनाता है।
