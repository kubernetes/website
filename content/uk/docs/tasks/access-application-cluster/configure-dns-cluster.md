<!-- overview -->

Kubernetes пропонує надбудову DNS для кластера, яка стандартно ввімкнена в більшості підтримуваних середовищ. У Kubernetes версії 1.11 і новіших рекомендовано CoreDNS, який стандартно встановлюється з kubeadm.

<!-- body -->

Докладніше про налаштування CoreDNS для кластера Kubernetes дивіться [Налаштування сервісу DNS](/docs/tasks/administer-cluster/dns-custom-nameservers/).
