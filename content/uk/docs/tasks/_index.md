Цей розділ документації Kubernetes містить сторінки, які показують, як виконувати окремі завдання. Сторінка завдання показує, як виконати одну дію, зазвичай за допомогою короткої послідовності кроків.

Якщо ви хочете написати сторінку завдання, дивіться [Створення запиту на злиття для документації](/docs/contribute/new-content/open-a-pr/).
