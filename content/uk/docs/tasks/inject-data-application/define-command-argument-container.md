## Визначення команди та аргументів під час створення Podʼа {#define-a-command-and-arguments-when-you-create-a-pod}

Під час створення Podʼа ви можете визначити команду й аргументи для контейнерів, які працюють у Podʼі. Щоб визначити команду, додайте поле `command` у файл конфігурації. Щоб визначити аргументи команди, додайте поле `args` у файл конфігурації. Команду й аргументи, які ви визначили, не можна змінити після створення Podʼа.

Команда й аргументи, які ви визначаєте у файлі конфігурації, перевизначають стандартну команду й аргументи, надані образом контейнера. Якщо ви визначаєте args, але не визначаєте команду, використовується стандартна команда з вашими новими аргументами.

{{< note >}}
Поле `command` відповідає `ENTRYPOINT`, а поле `args` — `CMD` у деяких середовищах виконання контейнерів.
{{< /note >}}

У цій вправі ви створите Pod, який запускає один контейнер. Файл конфігурації Podʼа визначає команду й два аргументи:

{{% code_sample file="pods/commands.yaml" %}}

1. Створіть Pod на основі файлу конфігурації YAML:

   ```shell
   kubectl apply -f https://k8s.io/examples/pods/commands.yaml
   ```

1. Перегляньте список запущених Podʼів:

   ```shell
   kubectl get pods
   ```

   Вивід показує, що контейнер, який працював у Podʼі command-demo, завершився.

1. Щоб побачити вивід команди, яка виконувалася в контейнері, перегляньте логи Podʼа:

   ```shell
   kubectl logs command-demo
   ```

   Вивід показує значення змінних середовища HOSTNAME та KUBERNETES_PORT:

   ```
   command-demo
   tcp://10.3.240.1:443
   ```

## Використання змінних середовища для визначення аргументів {#use-environment-variables-to-define-arguments}

У попередньому прикладі ви визначили аргументи безпосередньо, вказавши рядки. Замість прямого вказування рядків ви можете визначати аргументи за допомогою змінних середовища:

```yaml
env:
- name: MESSAGE
  value: "hello world"
command: ["/bin/echo"]
args: ["$(MESSAGE)"]
```

Це означає, що ви можете визначити аргумент для Podʼа будь-яким способом, доступним для визначення змінних середовища, зокрема за допомогою [ConfigMaps](/docs/tasks/configure-pod-container/configure-pod-configmap/) і [Secrets](/docs/concepts/configuration/secret/).

{{< note >}}
Змінна середовища вказується в дужках, `"$(VAR)"`. Це потрібно, щоб змінна розгорталася в полі `command` або `args`.
{{< /note >}}

## Виконання команди в оболонці {#run-a-command-in-a-shell}

Іноді потрібно, щоб команда виконувалася в оболонці. Наприклад, ваша команда може складатися з кількох команд, обʼєднаних у конвеєр, або бути скриптом оболонки. Щоб виконати команду в оболонці, оберніть її так:

```shell
command: ["/bin/sh"]
args: ["-c", "while true; do echo hello; sleep 10;done"]
```
