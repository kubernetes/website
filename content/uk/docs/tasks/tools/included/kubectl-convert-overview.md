Втулок для інструмента командного рядка Kubernetes `kubectl`, який дозволяє конвертувати маніфести між різними версіями API. Це може бути особливо корисно для міграції маніфестів на незастарілу версію API в новіших випусках Kubernetes. Докладніше дивіться в розділі [перехід на незастарілі API](/docs/reference/using-api/deprecation-guide/#migrate-to-non-deprecated-apis).
