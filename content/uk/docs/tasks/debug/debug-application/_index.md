---
title: Усунення несправностей застосунків
description: Налагодження поширених проблем контейнеризованих застосунків.
weight: 20
---

Цей розділ містить набір ресурсів для виправлення проблем із контейнеризованими застосунками. Він охоплює поширені проблеми з ресурсами Kubernetes (як-от Pods, Services або StatefulSets), поради щодо розуміння повідомлень про завершення контейнерів і способи налагодження запущених контейнерів.
