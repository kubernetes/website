Глобальний вимикач безпеки для правил валідації на стадії бета (`+k8s:beta`). Вимкніть його, щоб повернути ці правила в режим Shadow, якщо виявлено регресії.

У режимі Shadow декларативна валідація все одно виконується, а невідповідності реєструються та підраховуються, але вони не відхиляють запити; рукописна валідація залишається авторитетною.

Застосування для ресурсів, які використовують `WithDeclarativeEnforcement()`:

- Без префікса: завжди застосовується, незалежно від цієї функціональної можливості.
- `+k8s:beta`: застосовується, коли цю функціональну можливість увімкнено (стандартно), інакше в режимі Shadow.
- `+k8s:alpha`: завжди в режимі Shadow.

Ця функціональна можливість діє незалежно від функціональної можливості [`DeclarativeValidation`](/docs/reference/command-line-tools-reference/feature-gates/#DeclarativeValidation), яка керує лише звітуванням про невідповідності.
