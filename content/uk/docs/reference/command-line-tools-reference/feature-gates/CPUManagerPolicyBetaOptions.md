Дозволяє тонко налаштовувати політики CPUManager за допомогою експериментальних опцій бета-якості. Ця функціональна можливість захищає *групу* опцій CPUManager, які мають рівень якості бета. Ця функціональна можливість ніколи не буде переведена у стабільну версію.
