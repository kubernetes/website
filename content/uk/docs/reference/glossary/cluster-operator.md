Особа, яка налаштовує кластери, керує ними та стежить за їхньою роботою.

<!--more-->

Їхній основний обовʼязок — підтримувати кластер у робочому стані, що може охоплювати періодичне обслуговування чи оновлення.<br>

{{< note >}}
Оператори кластера — це не те саме, що [шаблон Operator](/docs/concepts/extend-kubernetes/operator/), який розширює API Kubernetes.
{{< /note >}}
