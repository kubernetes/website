Функція ядра Linux для емуляції привілеїв суперкористувача. Використовується для "контейнерів без прав root".

<!--more-->

Простори імен користувачів — це функція ядра Linux, яка дозволяє користувачеві без прав root емулювати привілеї суперкористувача ("root"), наприклад, щоб запускати контейнери, не будучи суперкористувачем поза контейнером.

Простір імен користувачів ефективно помʼякшує наслідки можливих атак із виходом за межі контейнера.

У контексті просторів імен користувачів термін "простір імен" вказує на функцію ядра Linux, а не на {{< glossary_tooltip text="простір імен" term_id="namespace" >}} у розумінні Kubernetes.
