Сімейство видів API для моделювання мережевої взаємодії сервісів у Kubernetes.

<!--more-->

Gateway API надає сімейство розширюваних, рольових видів API з урахуванням протоколів для моделювання мережевої взаємодії сервісів у Kubernetes.
