Колишній API розширення, який дозволяв застосункам, що працюють у кластерах Kubernetes, легко використовувати зовнішнє кероване програмне забезпечення, наприклад сервіс сховища даних, який пропонує хмарний провайдер.

<!--more-->

Це давало змогу переглядати та створювати зовнішні {{< glossary_tooltip text="керовані сервіси" term_id="managed-service" >}} і привʼязуватися до них, не потребуючи докладних знань про те, як ці сервіси створюються чи як ними керувати.
