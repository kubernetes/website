Особа, яка надає код, документацію або свій час для допомоги у проєкті чи спільноті Kubernetes.

<!--more-->

Внесками є pull requests (PR), тікети, відгуки, участь у {{< glossary_tooltip text="спеціальних групах за інтересами (SIG)" term_id="sig" >}} або організація заходів спільноти.
