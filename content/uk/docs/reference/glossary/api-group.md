Набір повʼязаних шляхів в API Kubernetes.

<!--more-->

Ви можете увімкнути або вимкнути кожну групу API, змінивши конфігурацію свого API-сервера. Ви також можете вимкнути або увімкнути шляхи до конкретних {{< glossary_tooltip text="ресурсів" term_id="api-resource" >}}. Група API полегшує розширення API Kubernetes. Група API вказується в шляху REST і в полі `apiVersion` серіалізованого {{< glossary_tooltip text="обʼєкта" term_id="object" >}}.

* Докладніше дивіться в розділі [Група API](/docs/concepts/overview/kubernetes-api/#api-groups-and-versioning).
