Програмне забезпечення, яке підтримує сторонній постачальник.

<!--more-->

Прикладами керованих сервісів (Managed Services) є AWS EC2, Azure SQL Database та GCP Pub/Sub, але це може бути будь-яке програмне забезпечення, яке може використовувати застосунок.
