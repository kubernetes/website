Пріоритет Podʼа вказує на важливість {{< glossary_tooltip term_id="pod" text="Podʼа" >}} порівняно з іншими Podʼами.

<!--more-->

[Пріоритет Podʼа](/docs/concepts/scheduling-eviction/pod-priority-preemption/#pod-priority) дає змогу встановлювати пріоритет планування Podʼа вищим або нижчим порівняно з іншими Podʼами — це важлива функція для робочих навантажень у промислових кластерах.
