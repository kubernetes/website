Розширення — це програмні компоненти, які розширюють Kubernetes і глибоко інтегруються з ним для підтримки нових типів обладнання.

<!--more-->

Багато адміністраторів кластерів використовують розміщений (hosted) екземпляр Kubernetes або екземпляр із дистрибутива. Такі кластери постачаються з попередньо встановленими розширеннями. Тому більшості користувачів Kubernetes не потрібно встановлювати [розширення](/docs/concepts/extend-kubernetes/), а створювати нові доведеться ще меншій кількості користувачів.
