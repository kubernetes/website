Постійно активний {{< glossary_tooltip text="учасник чи учасниця" term_id="contributor" >}} спільноти Kubernetes.

<!--more-->

Членам можна призначати тікети (issues) та pull requests, а також вони можуть брати участь у {{< glossary_tooltip text="спеціальних групах за інтересами (SIG)" term_id="sig" >}} через команди GitHub. Для pull requests від членів автоматично запускаються тести перед злиттям (pre-submit tests). Очікується, що член спільноти залишатиметься її активним учасником.
