CIDR (Classless Inter-Domain Routing) — це нотація для опису блоків IP-адрес, яка широко використовується в різних мережевих конфігураціях.

<!--more-->

У контексті Kubernetes кожному {{< glossary_tooltip text="вузлу" term_id="node" >}} призначається діапазон IP-адрес, заданий за допомогою CIDR через початкову адресу та маску підмережі. Це дозволяє вузлам призначати кожному {{< glossary_tooltip text="Podʼу" term_id="pod" >}} унікальну IP-адресу. Попри те, що спочатку це була концепція для IPv4, CIDR також розширили на IPv6.
