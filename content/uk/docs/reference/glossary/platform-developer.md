Особа, яка налаштовує платформу Kubernetes відповідно до потреб свого проєкту.

<!--more-->

Розробник платформи може, наприклад, використовувати [власні ресурси](/docs/concepts/extend-kubernetes/api-extension/custom-resources/) або [розширювати API Kubernetes за допомогою шару агрегації](/docs/concepts/extend-kubernetes/api-extension/apiserver-aggregation/), щоб додавати функціонал до свого екземпляра Kubernetes спеціально для свого застосунку. Деякі розробники платформи також є {{< glossary_tooltip text="учасниками проєкту Kubernetes" term_id="contributor" >}} і створюють розширення, які передають спільноті Kubernetes. Інші розробляють комерційні розширення із закритим вихідним кодом або розширення для конкретного середовища.
