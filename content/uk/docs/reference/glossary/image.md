Збережений екземпляр {{< glossary_tooltip term_id="container" text="контейнера" >}}, що містить набір програмного забезпечення, необхідного для запуску застосунку.

<!--more-->

Спосіб пакування програмного забезпечення, який дозволяє зберігати його в реєстрі контейнерів, завантажувати на локальну систему й запускати як застосунок. Образ містить метадані, які можуть вказувати, який виконавчий файл запускати, хто його зібрав та іншу інформацію.
