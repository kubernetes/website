HTTP API, що дає змогу користувачам, компонентам кластера та зовнішнім компонентам взаємодіяти між собою, а також запитувати або змінювати стан обʼєктів Kubernetes.

<!--more-->

Усі ресурси Kubernetes та "записи про наміри" зберігаються як обʼєкти API та модифікуються за допомогою RESTful викликів до API. API дозволяє керувати конфігурацією декларативним способом. Користувачі можуть взаємодіяти з API Kubernetes безпосередньо або за допомогою інструментів, таких як `kubectl`. Ядро API Kubernetes є гнучким, і його також можна розширити для підтримки власних ресурсів.
