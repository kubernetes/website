Пакет попередньо налаштованих конфігурацій Kubernetes, яким можна керувати за допомогою інструмента Helm.

<!--more-->

Чарти дають відтворюваний спосіб створення застосунків Kubernetes і обміну ними. Один чарт можна використати для розгортання чогось простого, як-от Pod memcached, або чогось складного, як-от повного стека вебзастосунку з HTTP-серверами, базами даних, кешами тощо.
