`kOps` не тільки допомагає створювати, видаляти, оновлювати та підтримувати кластери Kubernetes промислового рівня з високою доступністю, але й розгортає необхідну хмарну інфраструктуру.

<!--more-->

{{< note >}}
Наразі офіційно підтримується AWS (Amazon Web Services); підтримка DigitalOcean, GCE та OpenStack перебуває на стадії бета, а Azure — на стадії альфа.
{{< /note >}}

`kOps` — це система автоматизованого розгортання:

* Повністю автоматизоване встановлення
* Використовує DNS для ідентифікації кластерів
* Самозцілення: все працює в групах автоматичного масштабування (Auto-Scaling Groups)
* Підтримка різних операційних систем (Amazon Linux, Debian, Flatcar, RHEL, Rocky та Ubuntu)
* Підтримка високої доступності
* Може безпосередньо розгортати інфраструктуру або генерувати маніфести terraform
