Особа, відповідальна за високорівневий дизайн застосунку.

<!--more-->

Архітектор стежить за тим, щоб реалізація застосунку дозволяла йому взаємодіяти з навколишніми компонентами масштабовано й зручно для супроводу. До навколишніх компонентів входять бази даних, інфраструктура логування та інші мікросервіси.
