Інструмент командного рядка для взаємодії з {{< glossary_tooltip text="керівним вузлом" term_id="control-plane" >}} (control-plane node) кластера Kubernetes за допомогою API Kubernetes.

<!--more-->

Ви можете використовувати `kubectl` для створення, перегляду, оновлення та видалення обʼєктів Kubernetes.

<!-- localization note: OK to omit the rest of this entry -->
Англійською `kubectl` (офіційно) вимовляється /kjuːb/ /kənˈtɹəʊl/ (як "cube control").
