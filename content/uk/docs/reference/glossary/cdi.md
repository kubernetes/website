Container Device Interface (CDI) — це специфікація для налаштування пристроїв всередині контейнерів. Kubernetes використовує CDI разом із втулками пристроїв та динамічним виділенням ресурсів, щоб робочі навантаження отримували налаштування пристроїв, як-от bind mounts або змінні середовища, від середовища виконання.
