Особа, яка може переглядати та схвалювати внесок до коду Kubernetes.

<!--more-->

Тоді як рецензування коду зосереджене на якості та правильності коду, схвалення зосереджене на цілісному прийнятті внеску. Цілісне прийняття охоплює зворотну та пряму сумісність, дотримання домовленостей щодо API та прапорців, неочевидні проблеми з продуктивністю та правильністю, взаємодію з іншими частинами системи тощо. Статус затверджувача поширюється на частину кодової бази. Раніше затверджувачів називали супровідниками (maintainers).
