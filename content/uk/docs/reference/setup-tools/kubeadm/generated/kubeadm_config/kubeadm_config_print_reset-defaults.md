Виводить типову конфігурацію reset, яка може бути використана для 'kubeadm reset'

### Опис {#synopsis}

Ця команда виводить обʼєкти, такі як типова конфігурація команди reset, яка використовується для 'kubeadm reset'.

Зверніть увагу, що конфіденційні значення, такі як поля Bootstrap Token, замінюються значеннями-заповнювачами, такими як "abcdef.0123456789abcdef", щоб пройти перевірку, але не виконувати реальні обчислення для створення токена.

```
kubeadm config print reset-defaults [flags]
```
