Виводить типову конфігурацію init, яку можна використовувати для 'kubeadm init'

### Опис {#synopsis}



Ця команда виводить обʼєкти, такі як типова конфігурація init, яка використовується для 'kubeadm init'.

Зверніть увагу, що конфіденційні значення, такі як поля Bootstrap Token, замінюються значеннями-заповнювачами, такими як "abcdef.0123456789abcdef", щоб пройти перевірку, але не виконувати реальні обчислення для створення токена.


```
kubeadm config print init-defaults [flags]
```
