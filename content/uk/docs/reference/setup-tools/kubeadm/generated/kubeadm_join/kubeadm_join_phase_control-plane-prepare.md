### Опис {#synopsis}

Готує машину до обслуговування панелі управління

```
kubeadm join phase control-plane-prepare [flags]
```

### Приклади {#examples}

```
  # Prepares the machine for serving a control plane
  kubeadm join phase control-plane-prepare all
```
