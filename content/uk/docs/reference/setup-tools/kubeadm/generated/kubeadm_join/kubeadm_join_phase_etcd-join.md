### Опис {#synopsis}


Приєднує etcd для вузлів панелі управління

```
kubeadm join phase etcd-join [flags]
```

### Приклади {#examples}

```
  # Joins etcd for a control plane instance
  kubeadm join phase control-plane-join-etcd all
```
