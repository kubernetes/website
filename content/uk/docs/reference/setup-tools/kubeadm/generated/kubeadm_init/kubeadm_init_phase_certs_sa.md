### Опис {#synopsis}

Генерує приватний ключ для підпису токенів службових облікових записів разом із його публічним ключем та зберігає їх у файлах sa.key та sa.pub.

Якщо обидва файли вже існують, kubeadm пропускає крок генерації та використовує наявні файли.

```
kubeadm init phase certs sa [flags]
```
