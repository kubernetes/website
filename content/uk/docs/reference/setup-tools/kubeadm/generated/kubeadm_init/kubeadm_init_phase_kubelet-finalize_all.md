### Опис {#synopsis}

Запускає всі фази kubelet-finalize

```
kubeadm init phase kubelet-finalize all [flags]
```

### Приклади {#examples}

```
  # Updates settings relevant to the kubelet after TLS bootstrap
  kubeadm init phase kubelet-finalize all --config
```
