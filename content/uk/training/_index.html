Розвивайте свою карʼєру в cloud native

Kubernetes перебуває в самому серці руху cloud native. Навчання та сертифікація від Linux Foundation і наших партнерів з навчання дають змогу інвестувати у вашу карʼєру, вивчити Kubernetes і зробити ваші проєкти cloud native успішними.

Отримайте сертифікацію Kubernetes

Kubernetes and Cloud Native Associate (KCNA)

Іспит Kubernetes and Cloud Native Associate (KCNA) підтверджує базові знання та навички користувача в Kubernetes і ширшій екосистемі cloud native.

Сертифікат KCNA підтверджує концептуальні знання всієї екосистеми cloud native з особливим акцентом на Kubernetes.


Перейти до сертифікації
Kubernetes and Cloud Native Security Associate (KCSA)

KCSA — це передпрофесійна сертифікація для кандидатів, які прагнуть перейти на професійний рівень, продемонструвавши розуміння базових знань і навичок у сфері технологій безпеки в екосистемі cloud native.

Сертифікат KCSA підтверджує розуміння базової конфігурації безпеки кластерів Kubernetes для досягнення цілей відповідності вимогам (compliance).


Перейти до сертифікації
Certified Kubernetes Application Developer (CKAD)

Іспит Certified Kubernetes Application Developer засвідчує, що користувачі можуть проєктувати, створювати, налаштовувати та робити доступними застосунки cloud native для Kubernetes.

Фахівець із сертифікатом CKAD може визначати ресурси застосунків і використовувати основні примітиви для створення, моніторингу та усунення несправностей масштабованих застосунків та інструментів у Kubernetes.


Перейти до сертифікації
Certified Kubernetes Administrator (CKA)

Програма Certified Kubernetes Administrator (CKA) гарантує, що власники сертифіката CKA мають навички, знання та компетенції для виконання обовʼязків адміністраторів Kubernetes.

Сертифікований адміністратор Kubernetes продемонстрував уміння виконувати базове встановлення, а також налаштовувати кластери Kubernetes промислового рівня та керувати ними.


Перейти до сертифікації
Certified Kubernetes Security Specialist (CKS)

Програма Certified Kubernetes Security Specialist гарантує, що власник сертифіката впевнено й компетентно застосовує широкий спектр найкращих практик. Сертифікація CKS охоплює навички захисту контейнерних застосунків і платформ Kubernetes під час збирання, розгортання та виконання.

Кандидати на CKS повинні мати чинний сертифікат Certified Kubernetes Administrator (CKA), щоб підтвердити достатній рівень знань Kubernetes перед складанням іспиту CKS.


Перейти до сертифікації

Програма Kubestronaut: підвищуйте свою експертизу в Kubernetes

Програма Kubestronaut від CNCF відзначає видатних лідерів спільноти, які продемонстрували глибоку відданість опануванню Kubernetes. Ця престижна ініціатива виокремлює людей, які постійно інвестують у власне навчання та досягли найвищого рівня майстерності. Щоб отримати почесне звання Kubestronaut, потрібно успішно отримати та підтримувати чинними всі пʼять сертифікатів CNCF з Kubernetes: Certified Kubernetes Administrator (CKA), Certified Kubernetes Application Developer (CKAD), Certified Kubernetes Security Specialist (CKS), Kubernetes and Cloud Native Associate (KCNA) і Kubernetes and Cloud Native Security Associate (KCSA).
